# 🔵 JavaScript Counter

A simple and beginner-friendly **JavaScript Counter** built with HTML, CSS, and JavaScript.

Use the buttons to increase, decrease, or reset the counter.

## ✨ Features

* Increase the counter
* Decrease the counter
* Reset the counter to 0
* Counter cannot go below 0
* Simple and minimal interface
* Beginner-friendly HTML, CSS & JavaScript
* No external libraries or frameworks

## 🛠️ Built With

* **HTML** — Page structure
* **CSS** — Styling and button design
* **JavaScript** — Counter functionality

## 🚀 How It Works

1. The counter starts at `0`.
2. Click the **Increase** button to add `1`.
3. Click the **Decrease** button to subtract `1`.
4. The counter will not go below `0`.
5. Click the **Reset** button to return the counter to `0`.

The JavaScript updates the counter value dynamically whenever a button is clicked.

## 🎨 Interface

The project uses a simple interface with a large counter display and three buttons for controlling the value.

The buttons also include a hover effect for basic visual feedback.
